**SOLMAR — Streets of the Sun** is an original open-world crime game set in Solmar, a sun-soaked coastal city of plazas, palm avenues, a marina and harbour docks. You are Dario Voss, wheelman: steal cars for your sister Mara, grab the yellow Neon Sport and lose the Solmar PD, then hit the Vane family's harbour cash crates for $3,500. On foot and by car, with 7 original car models, live traffic and pedestrians, a 0–5 wanted system (foot cops, chasing cruisers that ram, roadblocks, a police helicopter), pistol combat with tracers, a dense HUD with a live circular minimap, a full city map, a day–sunset–night cycle with lit windows and neon signs, synthesized WebAudio radio, autosave and a story across three missions. Everything — city, characters, vehicles, story, art, sound — is original; nothing is taken from Rockstar or GTA.

## Run it

```sh
python3 -m http.server 8080 --directory game
# then open http://127.0.0.1:8080/ in a desktop browser
```

No build step, no network requests: the game is static files under `game/` (Three.js vendored at `game/vendor/three.module.min.js`).
